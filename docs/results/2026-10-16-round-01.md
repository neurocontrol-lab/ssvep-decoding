# Round 1: single-target SSVEP decoding

Recorded **16 October 2026**, approximately 01:30-02:13 IST (UTC+05:30). This report documents exploratory recordings from the current development setup. The session logs identify decoder version **0.1.0**.

The acquisition stream remained continuous in all seven recordings. The displayed target generally scored higher during stimulation than during short rest intervals. Forward showed the strongest target ranking; right remained the least distinct. No commands passed the default acceptance rules. Lowering the score threshold recovered some intended command emissions but also produced wrong-target and idle emissions.

Use terminal names when interpreting this montage. BioAmp distinguishes `IN-`, the negative differential signal input, from `REF`, its separately named electrode terminal, and from power `GND` ([manufacturer documentation](https://docs.upsidedownlabs.tech/hardware/bioamp/bioamp-exg-pill/index.html)). With the confirmed shared `IN-` connection at Cz, the measured channels are approximately **O1-Cz, O2-Cz, Oz-Cz, and POz-Cz**. The left mastoid was connected to the separately named REF terminal; it was not the negative input defining these channel differences. Do not interpret the shorthand "IN-/GND" as an instruction to connect an electrode to power GND. The terminal routing is confirmed, but the ADC-to-scalp-site assignment cannot be reconstructed from the information currently available. Channel-wise scores may be reported by ADC identity, but should not be assigned to particular scalp sites.

The sites are nominal operator-reported placements. No landmark measurement procedure, contact impedance measurements, or quantified electrode-position accuracy is available. Easier posterior scalp access and difficult top-of-head access are observations, not established explanations for the CCA results. Viewing distance and exact monitor model also remain unrecorded.

## Comparison method

Analysis used saved `events.jsonl` scores and `stimulus.json` cue markers, without changing the recorded scores or live configuration:

1. Match each named target recording to its single-target stimulus run using overlap in host `time.perf_counter` values.
2. Label a decision as interior stimulation/rest only when its `host_perf_counter` is at least **2.25 seconds after** that interval's `host_perf_counter_before_flip`, and at least **0.15 seconds before** the next interval begins. For the last rest, estimate its end from its marker plus its configured duration.
3. Within each group, calculate the attended target's mean CCA score, and count how often it has the largest score among all four candidates. No threshold or persistence gate is applied to this ranking statistic.
4. Analyze all windows in the separate rest-only recording for idle behavior.

This alignment is approximate. A decision timestamp is taken after host processing; the stimulus marker precedes a flip. MCU sampling and optical onset have no synchronized mapping. Excluding transitions reduces mixing but does not establish exact EEG trial boundaries. The 3-second rests leave only a small number of interior 2-second windows.

## Default decisions and rest baseline

The default configuration emitted **zero commands in all seven recordings**. The largest score in each stimulation recording stayed below the 0.55 score threshold. In the rest recording, backward briefly exceeded that threshold, but did not sustain eligibility long enough to emit.

| Candidate | Mean score during rest-only run | Maximum score |
|---|---:|---:|
| Forward | 0.279 | 0.434 |
| Backward | 0.239 | **0.582** |
| Left | 0.217 | 0.423 |
| Right | 0.189 | 0.325 |

Backward scores around 64.48 and 64.74 seconds were approximately 0.582 and 0.572; by 64.99 seconds the score was approximately 0.542. Persistence prevented this brief episode from producing a default command. Forward was the highest-scoring candidate in 171/287 rest windows, showing that a winning label alone is not a sufficient activation criterion.

Only `min_score` changed; margin remained 0.10, persistence 0.75 seconds, repeat interval 0.75 seconds, and original validity flags were retained. Filtering, CCA scores, and window lengths were not recomputed. This was an exploratory probe, not a selected or independently validated calibration.

## Interpretation and next comparison

1. Acquisition continuity is adequate for offline decoder comparisons on these received recordings; improving transport is not the first indicated intervention.
2. Forward is the strongest candidate in this round. Backward, left, and especially right require better separation or calibrated decision rules.
3. Persistence provided useful suppression of a brief idle score excursion. No false commands in one short baseline does not establish a general idle false-activation rate.
4. Compare 2-, 3-, and 4-second windows and harmonic counts offline before enabling keyboard output. Longer windows trade response latency for potentially more stable evidence; improvement has not yet been measured.
5. Define development/evaluation splits before selecting settings. Both `_01` and `_02` recordings have already been inspected, so the repeats are exploratory replication rather than untouched final test data. Reserve fresh recordings for final verification.
6. Add synchronized event labeling; record the new setup's terminal routing and ADC-to-electrode mapping, monitor settings, and viewing conditions. Evaluate simultaneous four-target operation after single-target discrimination and idle rejection are characterized.

No thresholds or decoder defaults were changed as a result of this round. Keyboard control remains disabled in the documented recordings.
